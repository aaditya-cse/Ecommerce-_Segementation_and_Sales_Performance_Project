### 3. Detailed Project Description (~250-500 words)
#### **The Problem:**
Modern e-commerce operators operate in a data-rich but insight-poor environment. Over 80% of data analyst time is wasted on data cleaning, deduplicating records, and handling missing values. Meanwhile, traditional BI tools (PowerBI, Tableau) are slow, expensive ($75+/user/mo), and generate static historical charts that provide zero forward-looking strategy. Most dangerously, existing LLM-based data analysis tools blindly execute AI-generated code with unrestricted `eval()` or `exec()`, exposing enterprises to malicious OS traversal, socket leaks, and CSV formula injection.

#### **The Solution: 5-Agent LangGraph Swarm:**
AgentOps BI Studio deploys a decentralized, self-healing multi-agent architecture where 5 specialized agents collaborate sequentially:
1. **🔍 Data Health Auditor:** Audits completeness, uniqueness, and hygiene to compute a deterministic Data Health Score (0-100) and imputes missing cells without skewing distributions.
2. **🛡️ AST Sandbox Analyst:** Verifies Python code through an Abstract Syntax Tree (AST) security whitelist before execution in a restricted memory sandbox, generating high-resolution analytical charts.
3. **🤖 AutoML Segmenter:** Runs unsupervised K-Means clustering across monetary, frequency, and order volume dimensions to stratify customers into operational cohorts (Champions, Core Repeat, At-Risk) with 30-day velocity forecasts.
4. **💡 What-If Modeler:** Simulates 3 dynamic business scenarios (Conservative, Aggressive, Hyper-Growth) modeling price elasticity, return rate shifts, and net retained margins.
5. **🧠 Boardroom Strategist:** Synthesizes verified execution logs into executive KPI cards, markdown comparison tables, and actionable board briefings.

#### **Key Technological Innovations:**
- **Zero-Hang Fail-Fast Architecture:** Reduced pipeline execution from 83s down to **< 4.4 seconds** (20x speedup) with deterministic self-healing failover.
- **Zero-Trust AST Security:** Hard-blocks dangerous calls (`eval`, `exec`, `__import__`, `open`, `subprocess`) and attribute traversals (`__subclasses__`).
- **CSV Formula Sanitization:** Neutralizes DDE code execution vectors (`=`, `+`, `-`, `@`).
- **60 FPS GPU-Composited UI:** Ambient particle constellation, 3D card tilt physics, and Web Audio API synthesized procedural sound effects.
- **Enterprise Verification:** 28/28 automated unit tests passing (100% pass rate).

### 4. Technical Architecture & Tech Stack

| Layer | Technology | Key Role |
| :--- | :--- | :--- |
| **Agent Orchestration** | LangGraph & LangChain | StateGraph multi-agent choreography, typed state passing, conditional self-healing edges |
| **LLM Inference** | Groq (`llama-3.3-70b-versatile`, `llama-3.1-8b-instant`) | Fast inference with hard 4.0s fail-fast timeout and local deterministic fallback |
| **Data Engine & ML** | Pure Python, NumPy, Pandas, Scikit-Learn | K-Means clustering, IQR outlier neutralization, median imputation, what-if sensitivity math |
| **Security Sandbox** | Python `ast` module, restricted builtins | AST syntax inspection, whitelist enforcement, zero arbitrary code execution |
| **Perimeter Defense** | SlidingWindowRateLimiter, Magic-Byte Validator | 30 req/min rate limiting, 5MB upload barrier, binary file rejection, strict CSP/HSTS |
| **Web Server & UI** | Flask, HTML5, Modern CSS, Web Audio API | Glassmorphism dashboard, 3D tilt physics, 60 FPS particle canvas, procedural audio feedback |
| **Testing & CI/CD** | Pytest | 28 automated unit tests testing all security, ML, rate limiting, and agent pipelines |
