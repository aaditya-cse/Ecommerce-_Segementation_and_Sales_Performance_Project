System Engineering

LangGraph StateGraph & Self-Healing Architecture

Flowchart & Execution Nodes
  • StateGraph Schema: Typed state dictionary passing CSV paths, profiles, stdout buffers, ML clusters, and scenario models across nodes.
  • Deterministic Fallback: If Groq LLM API is rate-limited, offline, or takes >4s, the engine seamlessly activates local deterministic self-healing code.
  • Pure Python Execution: Built with pure NumPy/Pandas algorithms with zero external C-dependencies.
Resilience & Speed Optimizations
  • Hard 4.0s Socket Cutoff: Configured request_timeout=4.0 and max_retries=0 on ChatGroq.
  • Zero Network Discovery: Model ID resolution happens instantaneously without blocking HTTP trips.
  • Sub-5s Benchmark: Complete 5-agent pipeline completes in 2.5s – 4.4s end-to-end.

Enterprise Hardening

Zero-Trust AST Security Sandbox & Injection Defense

AST Syntax Whitelist & Ban List
  • Pre-Execution AST Validation: Inspects AST nodes before code touches the Python runtime.
  • Forbidden Calls: Hard-blocks eval, exec, __import__, open, compile, globals, getattr, subprocess.
  • Dunder Traversal Blocked: Hard-blocks __subclasses__, __bases__, __builtins__, __class__.
  • Isolated Memory Scope: Restricted built-in environment allowing only benign math and plotting calls.
Perimeter & Input Protection
  • CSV Formula Injection Defense: Quotes dangerous Excel trigger prefixes (=, +, -, @, \t, \r).
  • Magic-Byte Validation: Validates file headers to reject disguised binary or executable payloads (ELF, PE, ZIP).
  • Sliding-Window Rate Limiter: Enforces 30 requests/minute per client IP to mitigate DoS threats.
  • Hardened HTTP Headers: Strict CSP, HSTS, X-Frame-Options: DENY, X-Content-Type-Options: nosniff.
